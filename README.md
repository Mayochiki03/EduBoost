# Classroom App (ชื่อโปรเจกต์ชั่วคราว)

ระบบห้องเรียนออนไลน์ สไตล์ Google Classroom + Quizizz สำหรับนักเรียนระดับ ม.ต้น
อ้างอิงแนวทางจาก Tatuga Class ตามตัวอย่างที่ให้มา

**Stack**: Node.js + Express + MongoDB (Atlas) + Cloudinary (เก็บไฟล์) ฝั่ง backend,
React + Vite + Tailwind ฝั่ง frontend, deploy บน Render

## 🐛 Bug fix log

- **[แก้แล้ว] Quiz options หายทุกครั้งที่สร้าง**: model `Quiz.js` ตอนแรกกำหนด schema ของ `options` เป็น `[{ text: String }]` (array ของ subdocument) แต่ controller และ frontend ทั้งหมดส่งข้อมูลเป็น `[String]` (array ของ string ธรรมดา) ตรงๆ ทำให้ Mongoose cast ข้อมูลไม่ตรง schema แล้ว**เงียบๆ ทิ้งข้อมูลเป็น array ว่างโดยไม่ error** — เจอตอนเขียน mock data script แล้วทดสอบ cast จริงเลยรู้ว่าตัวเลือกหายหมด แก้โดยเปลี่ยน schema เป็น `options: [String]` ให้ตรงกับที่ใช้งานจริงทั้งระบบ ทดสอบแล้วว่า cast ถูกต้อง

- **[แก้แล้ว] `Must supply api_key` ตอนอัปโหลดไฟล์**: เกิดจากใน `server.js` เรียก `dotenv.config()` หลัง import routes ต่างๆ ซึ่งใน ES Module import จะถูกรันก่อนโค้ดอื่นเสมอไม่ว่าจะเขียนตำแหน่งไหน ทำให้ `cloudinary.config()` ใน `config/cloudinary.js` (ถูกเรียกตอน import) ได้ค่า env เป็น `undefined` แก้โดยเปลี่ยนเป็น `import "dotenv/config"` เป็นบรรทัดแรกสุดของไฟล์แทน — ทดสอบแล้วว่าค่า `.env` โหลดถูกต้องก่อน routes ทำงาน

## สถานะปัจจุบัน: v1.1 — แก้บั๊ก Login + ระบบภาพต้นไม้ (Growth Assets) + ปรับ UI

### ✅ ทำเพิ่มจาก v1.0

**แก้บั๊ก login ("เด้งเฉยๆ ไม่รู้เกิดจากอะไร")** — เจอ 2 สาเหตุจริงและแก้แล้ว:
1. `client.js`: axios interceptor เดิม เจอ response 401 ปุ๊บคือ **force reload หน้าไปที่ `/login` ทันที** ไม่ว่า 401 นั้นจะมาจากอะไร — พอกรอกรหัสผ่านผิดตอน login เอง (ก็เป็น 401) หน้าจะรีโหลดทิ้งทันทีก่อนที่ error message จะทันโชว์ เลยรู้สึกเหมือน "เด้งเฉยๆ" ไม่มีคำอธิบาย แก้โดยเช็คว่า request นั้นมี token แนบไปด้วยหรือไม่ก่อนตัดสินใจ auto-redirect (401 จากการ login เอง = ไม่มี token แนบ = ไม่ redirect ปล่อยให้ฟอร์มโชว์ error ตามปกติ)
2. `AuthContext.jsx`: ฟังก์ชัน `login()` เดิมเรียก `refreshUser()` แบบไม่ await แล้วหน้า login ก็ `navigate()` ทันที บางครั้ง React state ยังอัปเดตไม่ทันตอน `ProtectedRoute` render ใหม่ เลยเห็น user เป็น null แล้วเด้งกลับหน้าแรกทั้งที่ login สำเร็จจริง (เป็นสาเหตุของ "บางทีก็ login ไม่ได้ทั้งที่กรอกถูก") แก้โดยทำให้ `login()` เป็น async และ await ให้เสร็จก่อน navigate เสมอ
3. เพิ่ม error message แยกกรณีเชื่อมต่อเซิร์ฟเวอร์ไม่ได้ (ไม่มี `err.response`) ออกจากกรณีรหัสผ่านผิด ให้รู้ชัดว่าปัญหาคืออะไร
4. Trim ช่องว่างหน้า-หลัง email อัตโนมัติก่อนส่ง (กันเคสพิมพ์ผิดจาก autocorrect บนมือถือ/แท็บเล็ต)

**ระบบภาพต้นไม้ (Growth Assets)** — ตามที่ขอ ให้แอดมินอัปโหลดภาพ/GIF เองแทนตัวการ์ตูน SVG เริ่มต้นได้:
- Model ใหม่ `GrowthAsset` เก็บ `{ level, imageUrl }` — ปรับ scale การเติบโตจาก 0-5 เป็น **0-10** ตามที่ขอ (10 ระดับ = 10 ภาพ, ระดับ 0 = ยังไม่ส่งงาน, 10 = โตเต็มที่)
- หน้า Admin เพิ่มเมนู "🌳 ภาพต้นไม้แต่ละระดับการเติบโต" — เห็นช่องอัปโหลดครบทั้ง 11 ระดับ (0-10) พร้อม preview, อัปโหลดทีละระดับแยกอิสระ, ลบรายระดับได้, **รองรับไฟล์ .gif ให้ต้นไม้ขยับได้ตามที่ขอ** (แค่ไฟล์ .gif ธรรมดา ระบบแสดงผลเป็น `<img>` เฉยๆ browser จะเล่น animation ของ gif ให้เองอัตโนมัติ ไม่ต้องเขียนโค้ด animation เพิ่ม)
- ฝั่งนักเรียน/หน้าดูอันดับ: ถ้าแอดมินอัปโหลดภาพของ level นั้นแล้ว จะโชว์ภาพ/gif ที่อัปโหลดแทนที่ตัวการ์ตูนเริ่มต้นทันที ถ้ายังไม่อัปโหลด **fallback กลับไปใช้ตัวการ์ตูน SVG เดิมอัตโนมัติ** ไม่มีจอว่างเปล่าระหว่างที่แอดมินยังอัปโหลดภาพไม่ครบ
- Cache ระดับ frontend กันเรียก API ซ้ำซ้อนหลายจุดในหน้าเดียว พร้อม invalidate cache อัตโนมัติทันทีที่แอดมินอัปโหลด/ลบภาพใหม่

**ปรับ UI ให้ดูเป็นมืออาชีพขึ้น**:
- เพิ่ม `Navbar.jsx` แบบ sticky ด้านบน ใช้ร่วมกันทุกหน้าหลัก (ครู/นักเรียน/แอดมิน) แทน header แบบเดิมที่ทำแยกแต่ละหน้าไม่เหมือนกัน — มี badge บอก role, backdrop blur ตอน scroll
- พื้นหลังทั้งแอปเปลี่ยนจากสีทึบเป็น radial gradient สีอ่อนๆ ผสมสีแบรนด์ (ฟ้า/ม่วง/เขียวมิ้นท์) จางๆ ให้ความรู้สึกพรีเมียมขึ้นแต่ไม่ล้นตา
- Modal ทุกจุดเพิ่ม backdrop blur ตอนเปิด (เดิมมีแค่สีดำโปร่งแสง)
- Build ผ่านจริงหลังปรับทุกจุด

## การติดตั้ง (Setup)

### 1. เตรียม MongoDB Atlas
1. สมัคร https://www.mongodb.com/cloud/atlas (ฟรี)
2. สร้าง Cluster (เลือก Free tier M0)
3. สร้าง Database User (username/password)
4. Network Access → Add IP `0.0.0.0/0` (อนุญาตทุกที่ เพราะ Render IP ไม่คงที่)
5. Connect → Drivers → คัดลอก connection string มาใส่ใน `.env`

### 2. เตรียม Cloudinary
1. สมัคร https://cloudinary.com (ฟรี)
2. หน้า Dashboard จะมี Cloud Name, API Key, API Secret — คัดลอกใส่ `.env`

### 3. ติดตั้ง backend
```bash
cd backend
cp .env.example .env
# แก้ไข .env ใส่ค่า MONGO_URI, CLOUDINARY_*, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm install
npm run seed     # สร้างบัญชีแอดมินคนแรก
npm run dev       # รันเซิร์ฟเวอร์ที่ http://localhost:5000
```

ทดสอบว่ารันสำเร็จ: เปิด `http://localhost:5000/api/health` ควรได้ `{"ok":true}`

### 4. Frontend
```bash
cd frontend
cp .env.example .env
# ค่า default ชี้ไปที่ backend localhost:5000 อยู่แล้ว ปกติไม่ต้องแก้ตอน dev
npm install
npm run dev       # เปิดที่ http://localhost:5173
```
ต้องรัน backend (ขั้นตอนที่ 3) ไว้พร้อมกันด้วย ไม่งั้นหน้า login/join จะเรียก API ไม่ติด

## ⚠️ สิ่งที่ควรทำก่อนใช้งานจริงกับนักเรียน (security checklist)

- **ปิดหรือจำกัด `POST /api/auth/register`** — ตอนนี้ endpoint นี้เปิดเผยสาธารณะ ใครก็สมัครเป็นครูได้ ใช้แค่ตอน setup ครั้งแรก (สร้างครูคนแรกผ่าน `npm run seed` แทนได้เลย ไม่จำเป็นต้องใช้ endpoint นี้อีก) แนะนำ comment บรรทัด `router.post("/register", ...)` ออกใน `authRoutes.js` หลัง setup เสร็จ แล้วสร้างครูคนอื่นผ่านหน้า Admin Panel (`/admin`) แทน
- เปลี่ยน `JWT_SECRET` ใน `.env` เป็นค่าสุ่มยาวๆ ห้ามใช้ค่าตัวอย่าง
- ตั้งรหัสผ่านแอดมิน (`ADMIN_PASSWORD`) ให้รัดกุม ไม่ใช่ค่าตัวอย่างใน `.env.example`
- จำกัด Network Access ของ MongoDB Atlas ให้แคบลงถ้าเป็นไปได้ (ตอน dev ใช้ `0.0.0.0/0` เพื่อความสะดวก แต่ถ้ารู้ IP ของ Render แน่นอนแล้วควรจำกัด)
